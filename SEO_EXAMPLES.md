# Exemple de Meta Tags Générés

Voici les meta tags qui seront générés dynamiquement pour chaque page de votre portfolio.

## Page d'Accueil (/)

### HTML généré dans le `<head>`:

\`\`\`html
<!-- Primary Meta Tags -->
<html lang="fr">
<title>Accueil | Maël Goujon - DevOps & Cyber-Sécurité</title>
<meta name="title" content="Accueil | Maël Goujon - DevOps & Cyber-Sécurité">
<meta name="description" content="Bienvenue sur le portfolio de Maël Goujon. DevOps et passionné de cyber-sécurité, découvrez mes projets universitaires et personnels.">
<meta name="keywords" content="développeur, full stack, portfolio, accueil, projets web">
<meta name="author" content="Maël Goujon">
<link rel="canonical" href="https://maelg.com/">

<!-- Open Graph / Facebook -->
<meta property="og:type" content="website">
<meta property="og:url" content="https://maelg.com/">
<meta property="og:title" content="Accueil | Maël Goujon - DevOps & Cyber-Sécurité">
<meta property="og:description" content="Bienvenue sur le portfolio de Maël Goujon. DevOps et passionné de cyber-sécurité, découvrez mes projets universitaires et personnels.">
<meta property="og:image" content="https://maelg.com/images/Me/me_square.jpg">
<meta property="og:locale" content="fr_FR">
<meta property="og:site_name" content="Maël Goujon Portfolio">

<!-- Twitter -->
<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:url" content="https://maelg.com/">
<meta name="twitter:title" content="Accueil | Maël Goujon - DevOps & Cyber-Sécurité">
<meta name="twitter:description" content="Bienvenue sur le portfolio de Maël Goujon. DevOps et passionné de cyber-sécurité, découvrez mes projets universitaires et personnels.">
<meta name="twitter:image" content="https://maelg.com/images/Me/me_square.jpg">
<meta name="twitter:creator" content="@maelgoujon">

<!-- Additional Meta Tags -->
<meta name="robots" content="index, follow">
<meta name="googlebot" content="index, follow">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta http-equiv="Content-Language" content="fr">
<meta name="theme-color" content="#000000">

## Comment Vérifier

### Dans le Navigateur
1. Ouvrir http://localhost:5174/
2. F12 → Onglet Elements
3. Développer `<head>`
4. Chercher les balises `<meta>` et `<title>`

### Avec les DevTools
\`\`\`javascript
// Dans la console du navigateur
console.log(document.title);
console.log(document.querySelector('meta[name="description"]').content);
console.log(document.querySelector('meta[property="og:title"]').content);
\`\`\`

### Avec curl (Terminal)
\`\`\`bash
curl -s https://maelg.com | grep -i "<title>"
curl -s https://maelg.com | grep -i "og:title"
curl -s https://maelg.com | grep -i "description"
\`\`\`

## Bonnes Pratiques Appliquées

✅ **Titres uniques** : Chaque page a un titre distinct
✅ **Longueur optimale** : Titres <60 char, descriptions <160 char
✅ **Mots-clés ciblés** : Keywords pertinents par page
✅ **URLs absolues** : Images avec domaine complet pour OG
✅ **Langue dynamique** : Attribut lang suit la préférence utilisateur
✅ **Canonical URLs** : Évite le duplicate content
✅ **Robots friendly** : index,follow sur toutes les pages

---

**Note**: Ces meta tags sont générés dynamiquement par React Helmet et changent selon la page et la langue active.
