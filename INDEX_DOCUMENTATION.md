## 📞 Support

### Questions Fréquentes

**Q: Les meta tags ne s'affichent pas ?**  
A: Voir la section Troubleshooting dans [SEO_CHECKLIST.md](./SEO_CHECKLIST.md)

**Q: Comment ajouter une nouvelle page ?**  
A: Voir la section "Adding New SEO Translations" dans [SEO_README.md](./SEO_README.md)

**Q: Le partage social ne fonctionne pas ?**  
A: Utiliser le Facebook Debugger pour forcer le scraping, voir [SEO_CHECKLIST.md](./SEO_CHECKLIST.md)

**Q: Comment modifier les traductions ?**  
A: Éditer `src/i18n/locales/fr.ts` et `en.ts`, section `seo`

### Besoin d'aide ?

1. Consultez d'abord la documentation appropriée ci-dessus

3. Lisez les exemples dans [SEO_EXAMPLES.md](./SEO_EXAMPLES.md)
4. Consultez les ressources externes listées
